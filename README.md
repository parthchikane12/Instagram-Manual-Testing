# 📱 Instagram Manual Testing Project

## 📌 Project Overview

This project demonstrates **Manual Testing of the Instagram application**.
The objective of this project is to simulate real-world QA activities such as creating **Test Cases, identifying Bugs, and preparing Test Reports**.

The testing focuses on major Instagram features like **Login, Profile, Feed, Post Upload, Comments, Notifications, and Direct Messaging**.

This repository is created as part of a **QA / Software Testing portfolio project**.

---

## 🎯 Project Objectives

* Perform **Manual Testing** on the Instagram application
* Create **detailed Test Cases**
* Identify and report **software bugs**
* Organize testing documentation in a structured format
* Demonstrate QA skills for **GitHub portfolio**
